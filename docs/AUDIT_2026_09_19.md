# Audit of the first v3.2 slice

Base: `4f8023b73f94987f2a9c65423f4d06afe4fed1dd` (PR #5).
The original suite passed: 119 tests, with 9 optional-backend tests skipped.
Eleven additional regression cases failed on that base, establishing the defects
below before changes to path supervision began.

| Defect | Correction and independent check |
| --- | --- |
| NaN tracking thresholds bypassed comparisons; infinite thresholds were accepted. | Reject all non-finite thresholds in both tracking entry points. Six parameterized regression cases. |
| Complex positions, energies, or gradients were silently cast to real values. | Reject complex inputs for these real observables. |
| Complex Hamiltonian Jacobians failed in implicit autograd. | Differentiate real and imaginary components separately; compare against an explicit Pauli-Y derivative and its parameter gradient. |
| A real model discarded the imaginary part of complex derivative targets. | Preserve complex targets in training and evaluation; verify the independently calculated nonzero residual. |
| The rank-based loss accepted non-ascending tracked energies. | Reject non-ascending targets in the one-geometry loss and evaluator. |
| Different model/target state counts could broadcast silently. | Require equal prediction and target shapes. |

The repaired suite passes 130 tests, with the same 9 optional-backend skips.
These fixes precede the next implementation commit. This is a targeted numerical
and API audit, not a proof that every possible defect has been excluded.
